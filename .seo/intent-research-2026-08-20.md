# Aakd US/UK SEO intent research — 2026-08-20

## Method and limits

This is a directional SERP sample, not keyword-volume research. Twenty English queries were sampled with web search on 2026-08-20, using US/UK modifiers where useful. Search results vary by location, time, personalization, and engine; therefore the named results below identify the type of competing answer, not a durable rank position. No search volume, ranking, customer demand, or competitor claim is inferred from the sample.

The sampled result set is recorded in the execution log for this work as `turn287`–`turn290`. Google Search Console becomes the source of truth once the property is verified.

## Priority decision

**Do not publish five keyword pages now.** The live production crawl foundation is broken, Search Console is unverified, and the program lacks the required original evidence assets. The first content asset should be the reproducible open-source clean-install → cited, reviewed action benchmark (clusters 1 and 3), because it gives a category evaluator and an operations user primary evidence without fabricating comparison or customer claims.

After the live matrix passes and the asset receives independent review, choose one public page from Search Console evidence. If no meaningful query data exists yet, publish the factual open-source CLM product-truth page first; it must link to the benchmark and self-hosting guide and remain distinct from the homepage.
